Sistema operativo:
Es el software principal del computador. Permite ejecutar programas y administrar los recursos del sistema.

Node.js:
Es un entorno que permite ejecutar código JavaScript fuera del navegador. Se utiliza para crear servidores y aplicaciones web.

Aplicación server.js:
Es el archivo donde se encuentra el código del servidor. Define las rutas y respuestas de la aplicación.

Puerto:
Es un punto de comunicación que permite recibir solicitudes. En esta actividad el servidor utiliza el puerto 3000.

Logs:
Son registros que guardan información sobre la actividad del servidor. Ayudan a detectar errores y monitorear el funcionamiento.
