Al enviar una petición POST a la ruta /registro con el siguiente JSON:

{
"nombre": "Maria",
"mensaje": "Hola comunidad"
}

El servidor responde:

{
"estado": "Datos recibidos",
"nombre": "Maria",
"mensaje": "Hola comunidad"
}

Esto demuestra que el servidor recibe los datos enviados mediante req.body y devuelve una respuesta en formato JSON.
